# API-Testing-Assistant
An AI-powered API Testing Assistant built with n8n that allows users to test API endpoints using simple natural-language instructions. It interprets requests, executes API calls, and explains the API responses in a clear, beginner-friendly format.
# AI-Powered Job and Internship Assistant

## About the Project
An AI-powered automation system built with n8n that helps users discover job and internship opportunities.

## Tools Used
- n8n
- AI Language Model
- RSS Feeds
- Email Integration

## How It Works
1. Collects job opportunities from RSS feeds.
2. Processes job information.
3. Uses AI to analyse and organise opportunities.
4. Delivers results through email.

- Data processing
